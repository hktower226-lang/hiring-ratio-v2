# 메뉴별 JSON 데이터 수정 안내

`index.html`이 아래 세 파일을 직접 읽습니다. HTML에는 데이터 사본을 넣지 않습니다. 데이터 수정 후 세 파일을 모두 읽고 검증한 결과로 화면을 갱신하며, 오류가 있으면 마지막 정상 데이터를 유지합니다.

| 번호 | 메뉴 | 파일 |
| --- | --- | --- |
| 1번 | 전체 · 월별 · 지부별 · 임대사별 | [01_전체_월별_지부별_임대사별.json](01_전체_월별_지부별_임대사별.json) |
| 2번 | 반도체 | [02_반도체.json](02_반도체.json) |
| 3번 | 전체비율 | [03_전체비율.json](03_전체비율.json) |

데이터 수정만으로 대수·비율·업체 분류·그래프가 다시 계산됩니다. GitHub Pages 배포가 끝난 후 화면의 **데이터 새로고침**, 페이지 새로고침, 화면 복귀 또는 화면을 보는 동안의 1분 주기 확인으로 반영됩니다. HTML 파일을 직접 열면 외부 JSON을 읽을 수 없으므로 웹서버에서 확인하세요.

## 1번 — 전체 · 월별 · 지부별 · 임대사별

첫 번째 엑셀 시트의 신규채용 기록입니다. ‘전체’ 화면 제목은 **26년 신규채용비율**이며 기본 화면입니다.

- `year`: 화면 연도입니다.
- `months`: 월별 메뉴에 표시할 월 번호 배열입니다. 1~12의 중복 없는 정수를 사용합니다.
- `categories`: `한노`, `민노`, `섬유`, `연합`, `직원`, `미정`의 이름과 순서를 유지합니다.
- `records`: 현장 기록 배열입니다. `id`는 중복되지 않아야 하고 `month`는 `months`에 있어야 합니다. `hireDate`는 입사일을 받은 경우 `YYYY-MM-DD` 형식으로 보관하며 이 날짜의 월로 등록합니다. `branch`는 지부, `rental`은 임대사, `contractor`는 원청사, `site`는 현장명입니다. `note`는 비고이며 없으면 빈 문자열입니다. 대수는 `total`, 소속별 대수는 `counts` 안에서 수정합니다. 모든 대수는 0 이상의 정수입니다.

임대사별 통계는 `rental`로 묶습니다. `contractor`로 바꾸지 않습니다. 한노 비율이 반올림 전 기준 40% 이상이면 **우호업체**, 30% 이하이면 **비협조업체**입니다. 그 사이에는 별도 분류를 표시하지 않습니다.

동일 현장은 임대사·원청사·현장명 세 항목으로 판별합니다. 세 항목이 같으면 같은 달 재요청은 기존 행을 갱신하고, 다른 달로 요청하면 이전 월에서 새 월로 이동하여 한 건만 유지합니다. 현장명이 비슷하다는 이유만으로 다른 임대사·원청사의 기록을 합치지 않습니다. 세부 작업 규칙은 루트 `AGENTS.md`에 있습니다. 검색은 선택 목록·상세 현장 목록에 적용되고 집계는 해당 범위 전체 기준입니다.

현재 기록은 63건·249대이며 한노 74, 민노 99, 섬유 9, 연합 6, 직원 31, 미정 31입니다. 시화MTV 지하주차장은 총 3대에 소속 합계가 4이고 ‘1대에 2명이 타고있음’이라는 비고가 있습니다. 이 1대 차이를 임의로 보정하지 않습니다.

## 2번 — 반도체

반도체 데이터는 1번 파일과 별도로 유지합니다.

- `records`: **반도체 현장(현재배정진행중)** 통계에 포함하는 현장입니다.
- `assignedRecords`: 배정 완료 현장입니다. 임대사 검색의 배정 완료 포함 통계에만 더합니다.
- 각 기록은 고유한 `id`, `rental`, `contractor`, `site`, `total`, `counts`, `note`를 가집니다. `categories`는 1번과 동일합니다. 월과 지부는 원본에 없으므로 만들지 않습니다. 원청사 공란은 빈 문자열로 보관하고 화면에서 **미기재**로 표시합니다.

반도체 메뉴 기본 통계는 `records`만 합칩니다. **임대사별 반도체 통계**에 업체명을 입력하면 해당 업체의 `records + assignedRecords`와 `records` 통계를 함께 표시합니다. 이 검색은 업체 통계·상세 목록·구분 버튼 건수에 적용됩니다. 일반 현장 검색과 진행중/배정 완료 목록 전환은 통계 합계를 바꾸지 않습니다. 임대사가 일치하지 않으면 빈 결과를 표시하고, 배정 완료만 있는 업체의 진행중 통계는 0대·0.0%입니다.

현재 진행중은 8건·112대(한노 39, 민노 48, 섬유 1, 연합 2, 직원 6, 미정 16), 배정 완료는 4건·28대입니다. 신우개발 검색은 배정 완료 포함 137대·11건 / 진행중 112대·8건, 타워랜드는 3대·1건 / 0대·0건입니다.

사용자 정정에 따라 P5 정수장 3기 신축공사는 배정 완료로 이동했습니다. P4 복합동·P4 대기방지는 진행중에서만 삭제했고 배정 완료에 있던 기록은 유지했습니다.

### 1번 화면과의 합산 경계

| 표시 | 합산 범위 | 현재 값 |
| --- | --- | --- |
| 전체누적(반도체현장제외) | 1번 `records` | 249대·63건 |
| 반도체 현장포함 | 1번 `records` + 2번 `records` | 361대·71건 |
| 반도체 기본 통계 | 2번 `records` | 112대·8건 |

2번 `assignedRecords`는 전체 메뉴의 어느 통계에도 넣지 않습니다. 월별·지부별·임대사별 메뉴는 계속 1번만 사용합니다. 전체 메뉴의 상세 검색과 목록도 1번 기록만 표시하며 반도체 상세는 반도체 메뉴에서 확인합니다.

## 3번 — 전체비율

세 번째 엑셀 시트의 **해당 월 전체 현황**입니다. 월별 신규채용이나 반도체 누적 기록과 집계 범위가 다릅니다. 이 파일을 1·2번 합계에 더하거나 10개월 숫자를 더해 현재 전체 대수로 사용하지 않습니다.

모든 월과 모든 소속을 한 화면에 표시합니다. 월·소속 선택 없이 1~10월 추이 그래프와 비율·대수 표를 봅니다. 안내 문구는 다음을 유지합니다.

> **미정 인원을 제외한 현재 기준입니다**
>
> 미정 인원을 제외한 총수를 기준으로 소속별 비율을 계산합니다. 미정을 포함한 전체대수 기준보다 각 소속비율이 조금더 높게 보입니다.

- `year`: 자료 연도입니다.
- `basis.unknownExcluded`: `true`입니다. 원본 총대수에 이미 미정 제외 기준이 적용되어 있으므로 다시 차감하거나 미정 수를 역산하지 않습니다.
- `basis.separatedFromMonth`: `10`입니다.
- `categories`: `한노`, `민노`, `섬유`, `연합`, `기타노조 미분리`, `직원`의 이름과 순서를 유지합니다.
- 월별 `records`에는 `month`, `total`, `counts`, `reportedPercentages`, `note`가 있습니다. 화면 비율은 `counts / total × 100`으로 계산하고 `reportedPercentages`는 엑셀 원문 비율을 보관합니다. 총대수는 양의 정수, 소속 대수는 0 이상의 정수입니다.
- 1~9월 섬유·연합은 원본 빈칸이므로 해당 `counts`와 `reportedPercentages`를 `null`로 유지합니다. 0으로 만들거나 개별 대수를 추정하지 않습니다.
- 10월부터 섬유와 연합을 나눕니다. 그래프는 9월 기타노조 미분리에서 10월 두 소속으로 갈라지며, 이 연결은 집계 구분 변경을 나타냅니다. 9월 35대(6.4%)에서 10월 섬유 16대(2.8%)·연합 19대(3.3%)로 표시합니다. 10월 표의 기타노조 칸도 둘로 나누며 원본 기타노조 미분리 0은 JSON에 유지합니다.
- 10월 총대수는 568대, 소속 합계는 569대입니다. 사용자 설명인 **“한 장비에 2명이 탑승하여 총대수와 소속 합계에 1대 차이가 있습니다.”**를 10월 `note`에 보관하고 비고로 표시합니다. 임의로 대수나 비율을 보정하지 않습니다.

## 수정할 때 공통으로 지킬 점

JSON 문법, 필드 이름, 소속 이름을 유지하고 대수와 필요한 기록만 바꾸세요. 한글 문자열은 UTF-8 그대로 저장합니다. 원본 업로드 엑셀은 수정하지 않으며 사용자가 요청한 정정은 해당 JSON에 반영합니다. 합계·비율은 프로그램이 계산하므로 HTML에 숫자를 별도로 복사하지 않습니다. 소수점 첫째 자리 반올림 또는 실제 장비·소속 집계 차이로 비율 합계가 100%와 다를 수 있습니다.
