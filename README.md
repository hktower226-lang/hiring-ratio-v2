# 경기지역본부 채용비율

모바일에서 전체·월별·지부별·임대사별 신규채용 현황, 반도체 현장, 월별 전체채용비율을 확인하는 정적 웹사이트입니다. 화면은 `index.html`, 데이터는 아래 JSON 세 파일에서 관리합니다.

| 번호 | 담당 메뉴 | 수정할 데이터 파일 |
| --- | --- | --- |
| 1번 | 전체 · 월별 · 지부별 · 임대사별 | [01_전체_월별_지부별_임대사별.json](data/01_전체_월별_지부별_임대사별.json) |
| 2번 | 반도체 | [02_반도체.json](data/02_반도체.json) |
| 3번 | 전체비율 | [03_전체비율.json](data/03_전체비율.json) |

‘전체’ 메뉴의 **반도체 현장포함** 비교 통계에는 1번 데이터에 2번의 현재 배정 진행중 현장만 더합니다. 2번의 배정 완료 기록과 3번 월별 전체 현황은 이 합계에 넣지 않습니다.

## 데이터 수정과 화면 반영

데이터 수정만 필요하면 해당 JSON을 고치면 됩니다. HTML 안에 데이터 사본이 없으므로 HTML을 함께 고치거나 빌드할 필요가 없습니다. 대수·비율·업체 분류·그래프는 읽어 온 데이터로 다시 계산합니다.

GitHub에서 JSON을 수정하고 `main`에 커밋한 뒤 Pages 배포가 완료되면, 사이트에 새로 접속하거나 **데이터 새로고침**을 누르거나 페이지를 새로고침해 확인할 수 있습니다. 모바일 데이터 사용을 줄이기 위해 주기적인 확인이나 화면 복귀 시 자동 갱신은 하지 않습니다. 열어 둔 화면은 직접 새로고침할 때 최신 데이터로 바뀝니다. 갱신 중 파일을 읽지 못하거나 JSON 형식에 오류가 있으면 마지막 정상 화면을 유지하고 안내합니다.

JSON의 문법과 필드 구조를 유지하세요. 어떤 항목을 바꿀지 모르면 [데이터 설명](data/README.md)을 참고하면 됩니다.

## Codex에 수정 요청하기

이 저장소를 연결한 현재 Codex 대화에서 이어가면 기존 작업 맥락을 활용할 수 있습니다. 다음처럼 메뉴나 번호와 변경 내용을 알려 주세요.

- “1번 JSON의 10월 ○○현장 한노를 2대로 수정해줘.”
- “2번 반도체 JSON에서 ○○현장을 배정 완료로 옮겨줘.”
- “3번 전체비율 JSON의 11월 자료를 추가해줘.”

Codex는 메뉴와 파일을 대응시켜 수정하고 관련 집계를 확인할 수 있습니다. 새 Codex 대화에서도 같은 저장소를 연결하고 **`AGENTS.md`와 `data/README.md`를 읽고 이어서 작업해 달라**고 요청하면 됩니다. 일반 ChatGPT 대화는 저장소에 직접 쓰는 연결이 없는 경우 파일 전달·수동 업로드가 필요할 수 있으므로, 저장소 수정과 업로드는 Codex에서 진행하는 편이 편리합니다.

## 실행과 배포

설치나 빌드는 필요하지 않습니다. 저장소 루트에서 다음 명령으로 확인합니다.

```sh
python -m http.server 8000 --bind 0.0.0.0
```

외부 JSON을 읽으므로 HTML을 파일로 직접 여는 대신 HTTP/HTTPS 웹주소로 열어야 합니다. 배포 방법은 [DEPLOY.md](DEPLOY.md), 개발·집계 규칙은 [AGENTS.md](AGENTS.md)에 있습니다.
